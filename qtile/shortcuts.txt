WINDOW MANAGEMENT
  Mod + h/j/k/l                Move focus left/down/up/right
  Mod + Shift + h/j/k/l        Move window left/down/up/right
  Mod + Ctrl + h/j/k/l         Grow window left/down/up/right
  Mod + n                      Reset all window sizes
  Mod + w                      Kill focused window
  Mod + f                      Toggle fullscreen
  Mod + g                      Toggle floating
  Mod + Tab                    Next layout
  Mod + Shift + Return         Toggle split

APPLICATIONS
  Mod + t                      Launch terminal (Alacritty)
  Mod + e                      Launch file manager (Thunar)
  Mod + b                      Launch browser (Firefox)

ROFI LAUNCHERS
  Mod + d                      Application launcher (drun)
  Mod + r                      Run command
  Mod + p                      Window switcher
  Mod + v                      Clipboard history
  Mod + Shift + s              Web search
  Mod + Shift + n              Quick notes

MEDIA CONTROLS - Volume
  XF86AudioRaiseVolume         Volume up (+5%)
  XF86AudioLowerVolume         Volume down (-5%)
  XF86AudioMute                Toggle mute
  Mod + Shift + p              Volume up (alternative)
  Mod + Shift + o              Volume down (alternative)
  Mod + Shift + 0              Toggle mute (alternative)

MEDIA CONTROLS - Playback
  XF86AudioPlay                Play/Pause
  XF86AudioNext                Next track
  XF86AudioPrev                Previous track
  Mod + Shift + i              Play/Pause (alternative)
  Mod + Shift + u              Next track (alternative)
  Mod + Shift + y              Previous track (alternative)

SCREENSHOTS
  Print Screen                 Screenshot with selection (Flameshot)
  Mod + s                      Screenshot with selection (Flameshot)

QTILE CONTROLS
  Mod + Ctrl + r               Reload Qtile config
  Mod + Ctrl + q               Quit Qtile

SCRATCHPAD OVERLAYS
  Mod + Ctrl + s               Sound mixer overlay (pavucontrol)
  Mod + Ctrl + t               Terminal overlay
  Mod + Ctrl + 1               Show this shortcuts overlay
  Mod + Ctrl + 2               Show keyboard layout overlay

WORKSPACE SWITCHING
  Mod + 1-9                    Switch to workspace 1-9
  Mod + Shift + 1-9            Move window to workspace 1-9

═══════════════════════════════════════════════════════════════════════════════════════════
Note: "Mod" is typically the Super/Windows key
Press q or Mod+Ctrl+1 to close this overlay
